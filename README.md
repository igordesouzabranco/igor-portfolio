# igor-portfolio

Meu portfólio, mas rodando direto no terminal. 🐍

## Como rodar

Precisa só do Node.js instalado:

```bash
npx igor-portfolio
```

## O que tem dentro

- **Sobre**: quem eu sou e minha stack
- **Projetos**: Origo API, Collegium API e ContJS
- **Contato**: GitHub, LinkedIn e site
- **Formação**: cursos e estudos

## Feito com

Node.js puro, sem nenhuma dependência. O visual usa códigos ANSI de cor, tela alternativa do terminal e uma cobra em ASCII gerada a partir de uma imagem.
